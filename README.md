# Quickshell config

```sh
qs ipc call controlCenter toggle
qs ipc call controlCenter open
qs ipc call controlCenter close
```


```sh
qs ipc call volume raise # Increase by 5 percentage points.
qs ipc call volume lower # Decrease by 5 percentage points.
qs ipc call volume mute  # Toggle mute.
qs ipc call -- volume show
qs ipc call volume hide
```
